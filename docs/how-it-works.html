cfa-analyst · How it works

A CFA analyst that shows its working

Ask a question or hand over an Excel model. Claude follows the skill's five-step method, computes every figure in tested code, and cites the curriculum page it relied on.

The headline

Every number comes from tested code

Claude does no arithmetic in its head. 493 formulas cover all ten CFA topics. 691 unit tests check them against the curriculum's own worked examples, and a separate re-implementation ran 5,197 checks with zero failures.

Install

Three commands

git clone https://github.com/quincysting/claudeskill_cfa_analyst ~/.claude/skills/cfa-analyst
pip install numpy scipy openpyxl xlrd pytest
python ~/.claude/skills/cfa-analyst/scripts/check_all.py

Then ask Claude any investment question, or give it a model to review.
